# ExpiryX PWA

Progressive Web App for **ExpiryX** — lives inside this repo at `pwa/`, builds to `app/` at repo root.

## Setup

```bash
cd pwa
npm install
cp .env.example .env
npm run dev
```

Dev server: [http://localhost:5173/app/](http://localhost:5173/app/)

## Build for production

```bash
cd pwa
npm run build
```

Output goes to `../app/` — served alongside the landing page at `./app/`.

## Environment

| Variable | Default |
|----------|---------|
| `VITE_API_BASE_URL` | `https://doctracker-backend.onrender.com` |
| `VITE_APP_PLATFORM` | `web` |
| `VITE_APP_VERSION` | `1.0.0` |
| `VITE_APP_BUILD` | `1` |
